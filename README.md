# Erick Omondi Aketch — Academic Portfolio

A responsive researcher/academic portfolio for GitHub Pages.

## Included

- Animated mathematical network background
- Professional hero section with profile-photo support
- Dark/light mode with local storage
- Research interests
- GitHub project links
- Publications section
- Blog with standalone article pages
- CV download
- Responsive mobile navigation
- Contact section

## Important personalization

1. Put your professional photo at `assets/profile.jpg`.
2. Put your latest CV at the repository root as `cv.pdf`.
3. Replace `your-email@example.com`.
4. Replace LinkedIn, Google Scholar and ResearchGate `#` links.
5. Replace placeholder publication entries with your real publications.
6. Replace project links with your actual GitHub repository URLs.
7. Remove any publication/title that is only a placeholder.

## Deploy

Create a repository named:

`ErickAketch.github.io`

Upload all files and folders, then open **Settings → Pages → Deploy from a branch → main → /(root)**.

Your site will be:

`https://ErickAketch.github.io`

## GitHub Pages

This package is ready to publish from the repository root. The `index.html` file is at the repository root, and `.nojekyll` prevents unnecessary Jekyll processing.
